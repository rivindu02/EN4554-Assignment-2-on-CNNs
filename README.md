## Experimental protocol

- Fixed-seed split of CIFAR-10's training set into 45,000 training and 5,000 validation images.
- Channel means and standard deviations computed from the training split only.
- Task 1: explicit manual gradients, autograd and centred finite-difference checks, MLP training, and gradient norms across ten layers.
- Task 2: custom momentum SGD and bias-corrected Adam; reference comparisons, quadratic trajectories and three learning rates per optimizer.
- Task 3(a): seven regularization configurations on 5,000 training images, three seeds each.
- Task 3(b): plain and residual networks at depths 8, 20 and 56 with matching parameter counts at each depth.
- Task 4: validation tuning and six ablations; final model uses 420,670 parameters and 20 training epochs.

The saved final model reports **90.70% validation accuracy** and **90.08% test accuracy**. These are recorded outputs, not independently reproduced results. See the submission review for consistency checks still needed before treating the report as final.
